# Cyber City: Mini Open World 3D Game

> **Как запустить готовую сборку / How to run the ready-made build:** см. / see [HOW_TO_PLAY.md](../../HOW_TO_PLAY.md) в корне репозитория / in the repository root. Если ниже упоминаются другие файлы запуска — их в этом репозитории нет / if other launch files are mentioned below, they are not part of this repository.

Полноценная браузерная 3D open-world игра-песочница с открытым миром, физикой вождения, симуляцией трафика и пешеходов, полицией и миссией.

## Как запустить БЕЗ Vite (Самый простой и быстрый способ)

В архиве уже находится готовый файл `index.html`. Для него **НЕ ТРЕБУЮТСЯ** Node.js, Vite или npm!

### Способ 1: Прямое открытие
Просто дважды кликните по файлу `index.html` в проводнике (Windows / macOS / Linux) — он откроется в вашем браузере (Chrome, Edge, Firefox, Safari, Brave) и сразу начнет игру!

### Способ 2: Через любой локальный статический сервер
Если хотите запустить через локальный сервер:
- **Python 3:**
  ```bash
  python3 -m http.server 8000
  ```
  и откройте в браузере `http://localhost:8000`

- **Node / npx:**
  ```bash
  npx serve .
  ```

## Как запустить через Vite + React + TypeScript (для разработчиков)

В архиве также находится исходный код на React + TypeScript + Three.js:

```bash
npm install

```

Сервер разработки запустится по адресу `http://localhost:3000`.

## Управление в игре (Controls)

- **W, A, S, D** или **Стрелочки**:
  - Пешком: перемещение персонажа в 4 направлениях (с анимацией шага и поворотом).
  - В автомобиле: газ, тормоз, задний ход, плавный поворот руля.
- **E**: Сесть в автомобиль / Выйти из автомобиля (когда машина замедлилась).
- **Пробел (Space)**:
  - Пешком: прыжок.
  - В автомобиле: ручной тормоз (занос, дрифт с искрами и дымом из-под колес).
- **H**: Автомобильный клаксон (звуковой сигнал, пугающий пешеходов).
- **C**: Переключение камеры (3rd Person Follow / Hood Cam / Orbit View).
- **R**: Быстрый перезапуск миссии / сброс состояния.
- **M**: Включение / выключение звука (Web Audio API).

## Реализованные системы (Implemented Gameplay Systems)

1. **3D Мир (World & Map):**
   - 9 крупных перекрестков, сеть дорог с разметкой и пешеходными переходами.
   - 32+ уникальных трехмерных здания с окнами, крышами, антеннами и вентиляцией.
   - Центральный парк с газоном, деревьями и фонтаном.
   - Морской порт с грузовыми кранами и штабелями разноцветных морских контейнеров.
   - Окружающие границы города и динамическое освещение со светотенями.

2. **Персонаж (Player on Foot):**
   - Человекоподобная процедурная 3D модель с анимацией конечностей при беге.
   - Честная коллизия с домами, стенами, заборами и машинами.
   - Подход к любой машине и посадка по кнопке `[E]` с подсказкой на экране.

3. **Физика автомобилей (Vehicle Simulation):**
   - Спорткар `Prototype GT`, полицейские перехватчики, городское такси, седаны и пикапы.
   - Проработанные 3D модели: салон, тонировка, светящиеся фары с прожекторами (SpotLight), стоп-сигналы, вращающиеся и поворачивающиеся колеса.
   - Физическая модель: ускорение, инерция, аэродинамическое сопротивление, сцепление шин, торможение, занос при зажатом пробеле, дым из-под колес, искры и вмятины при столкновениях.
   - Выход из машины на безопасную сторону без застреваний в стенах.

4. **Пешеходы (NPC Pedestrians):**
   - Десятки прохожих, гуляющих по тротуарам и парку.
   - Конечности раскачиваются при ходьбе, выбираются случайные маршруты и паузы.
   - Реакция на опасность: при приближении быстрой машины пешеходы паникуют и убегают с криками, размахивая руками.
   - При сбивании машиной — физическое падение и начисление уровня розыска полиции.

5. **Трафик (Traffic NPCs):**
   - Автомобили независимо перемещаются по полосам движения.
   - Сканирование препятствий спереди: торможение перед машинами и пешеходами.
   - Проезд перекрестков со случайным выбором поворота.

6. **Полиция и система розыска (Police Pursuit):**
   - 3 уровня розыска (★, ★★, ★★★).
   - Активация стробоскопов (красно-синие мигалки) и сирены (Web Audio).
   - ИИ полиции: активный перехват игрока, таран и блокировка.
   - Система ухода от погони: при отрыве дальше 55 метров включается таймер (10 сек). Если скрыться — розыск снимается.

7. **Сюжетная миссия "The Syndicate Prototype":**
   - 4 стадии с маркерами и подсказками на мини-карте.
   - Золотой луч-маяк в небе у гаража синдиката.
   - Угон суперкара `Prototype GT`, тревога и облава полиции.
   - Доставка машины через город в доки (грузовой отсек №4) и парковка в зеленой голографической зоне.
   - Итоговое окно с временем доставки, максимальной скоростью и кнопкой перезапуска `[R]`.

8. **HUD и Радар (Mini-Map):**
   - Круглый радар в реальном времени: отображает дороги, дома, игрока, полицию, трафик и маркер цели.
   - Спидометр: цифровой спидометр (KM/H), градиентная шкала оборотов, название авто.
   - Звезды розыска с анимацией пульсации.
   - Контекстные плашки подсказок `[E] Enter / Exit`.

9. **Аудио-движок (Web Audio API):**
   - 100% процедурный звук в реальном времени без внешних файлов: обороты двигателя, визг шин, удары, сирена, гудок, фанфары победы.
